# pullminder-e2e-test

[![Pullminder](https://api.pullminder.com/badge/t_11348cc838d59b3eb8c1f56a72f9ffb4.svg)](https://pullminder.com)

Automated test repository for Pullminder nightly E2E tests.

**Do not modify this repository manually.**

This repo is used by the nightly E2E workflow in
[Upmate/pullminder.com](https://github.com/Upmate/pullminder.com).
The workflow creates ephemeral branches and PRs to test the full
Pullminder webhook → analysis → comment pipeline.
